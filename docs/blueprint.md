# **App Name**: BoldFolio

## Core Features:

- Dynamic Profile Section: Display user's name, role, a brief bio, and a professional photo. This content will be dynamically loaded.
- Contact & Social Links: Showcase email, phone, and LinkedIn contact details with appropriate icons, linked to user profiles.
- Skills & Technologies Showcase: Display a categorized list of technical skills and programming languages the user is proficient in.
- Project & Experience Portfolio: Present a structured list of past experiences and projects, including descriptions, roles, and relevant links, similar to the referenced website structure.
- Content Management via Firebase: Enable the user to easily update and manage their portfolio content (projects, experiences, skills) using a Firebase backend without requiring code changes.
- AI-powered Content Refinement Tool: An integrated tool to help the user generate compelling and professional descriptions or summaries for their projects and experiences using AI.
- Modular & Responsive UI with Bootstrap: Develop all UI components as separate, prop-driven modules, and ensure a fully responsive layout across all devices using Bootstrap for consistent styling.

## Style Guidelines:

- Light color scheme, centered around violet. Background color: A very light, desaturated lilac (#F9F7FA), almost white, providing a clean canvas. Primary color: A muted but rich violet (#6D409B) for headings, accents, and key interactive elements, offering professional contrast. Accent color: A vibrant blue-violet (#5861DB) to draw attention to call-to-actions and important information, complementing the primary palette.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-oriented, and distinctive feel. Body text font: 'Inter' (sans-serif) for high readability and a clean, objective aesthetic across the portfolio.
- Utilize modern, line-based vector icons for clear and intuitive representation of contact information (email, phone, LinkedIn) and other portfolio sections. Icons should be subtle and complement the minimalist design.
- A clean, modern, and spacious layout using Bootstrap's grid system for responsiveness. Content sections should be well-defined with adequate padding and margin for readability and visual appeal on all screen sizes.
- Subtle and functional micro-animations for interactive elements like buttons, link hovers, and section transitions to enhance user experience without being distracting. Easing in/out effects for smooth UI updates.
